## Descrição

Este projeto é um site desenvolvido em HTML sobre o Club de Regatas Vasco da Gama. O objetivo é apresentar a história, algumas conquistas e informações sobre o clube, utilizando estrutura semântica e recursos de acessibilidade.

## Páginas do site

- `index.html` — Página inicial, com apresentação do Vasco.
- `sobre.html` — Informações sobre a história e o clube.
- `dados.html` — Tabela de títulos e conquistas.
- `cadastro.html` — Formulário de cadastro.
- `contato.html` — Informações e formulário de contato.

## Como abrir o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Utilize o menu para navegar pelas páginas.

## Acessibilidade

O projeto utiliza:
- HTML semântico.
- Textos alternativos nas imagens informativas.
- Rótulos associados aos campos dos formulários.
- Navegação por links.
- Link para pular diretamente ao conteúdo principal.
- Indicação da página atual no menu.
